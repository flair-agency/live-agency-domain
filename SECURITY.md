# Security policy

This repository contains reviewed public LIVE agency domain source and is still undergoing hosted qualification. It does not currently establish a released product support policy or response-time commitment.

# Reporting a vulnerability

Do not report unpatched vulnerabilities, credentials, private source evidence, or personal data in public issues or pull requests.

GitHub private vulnerability reporting is currently disabled for this repository. No verified alternative private reporting address is published here. A private reporting route requires a maintainer decision; do not assume that a public issue, an organization profile, or another repository provides a confidential channel. Until a route is confirmed, retain sensitive details privately rather than posting them publicly.

For ordinary project questions that do not expose security details, see [support](SUPPORT.md). No service-level agreement or guaranteed response time is offered.
