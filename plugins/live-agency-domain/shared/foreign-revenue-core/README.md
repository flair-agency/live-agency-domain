Input evidence flags/counts do not prove source verification or service lookup completeness.

Build with the repository's locked TypeScript compiler and distribute as a standard npm file dependency. The package contains emitted JavaScript and declarations; no TypeScript loader runs inside `node_modules`. Registry publication is disabled. Neither the package nor its installation selects private mappings, an actor, account, environment, service or allowed write.

The recognition entry uses `buildPlan('recognition', input)`. This public extraction exposes recognition only; the original settlement implementation remains with its existing owner. A ready plan is not approval or registration. Real input, credentials, private profiles and concrete service IDs stay with their private owners.
