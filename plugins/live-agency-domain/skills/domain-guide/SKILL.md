# LIVE agency domain guide

Read [business contexts](references/contexts.md) for agency meaning and [knowledge ownership](references/ownership.md) for responsibility and disclosure questions. These are distribution copies of `docs/domain/contexts.md` and `docs/architecture/ownership.md` in `flair-agency/live-agency-domain`, not independently maintained authorities.

Explain only what the references establish, cite the relevant reference and section, and identify missing knowledge. Keep source observations, agency decisions and accounting facts distinguishable. Do not fill a gap with a private platform rule, guessed mapping, resource ID or an installed tool's schema.

For example, a missing invitation-eligibility observation does not establish ineligibility. Explain that distinction from the Creator Scouting section. If asked which service field implements eligibility, point to the organization mapping and selected environment owners; this package contains no such binding.

If a required reference is absent or unreadable, report the missing path and stop the affected explanation. A human can follow the same references and compare the answer with their wording. This guide does not select an actor, operational environment, credentials or service permissions, and performs no business writes.
